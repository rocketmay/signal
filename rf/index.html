How to use this on a phone
  1. Android: Chrome. Open this page over HTTPS (GitHub Pages), tap Add to Home Screen, then Connect. Bluetooth only works in a secure context.
  2. iPhone: Safari cannot do Web Bluetooth. Use the Bluefy browser, or nRF Connect for raw UART until a native app exists.
  3. Flash Node B with firmware v4.9-hello. Device name is RF-Link-B. The page shows that tag after Connect.
  4. Carry the phone with Node B. Load this page once while you have data, so it still works in a field with no cell service.
  5. Tap Mark as you walk so RSSI and loss line up with distance notes. Export CSV when you are done.
  6. Add ?demo=1 to the URL to preview charts without a board.
