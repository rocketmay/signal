How to use this on a phone
  1. Android: Chrome. Open this page over HTTPS (GitHub Pages), tap Add to Home Screen, then Connect. Bluetooth only works in a secure context.
  2. iPhone: Safari cannot do Web Bluetooth. Use the Bluefy browser, or nRF Connect for raw UART until a native app exists.
  3. Flash Node B with firmware matching the tag shown after Connect. Device name is RF-Link-B.
  4. Range mode: charts + loss stats for walk tests. Foxhunt mode: warmer/colder HUD, map trail, and beacon estimate.
  5. In Foxhunt, allow location. The blue dot is you. Tap Start hunt and walk — crumbs drop as you move. Estimate appears after enough points.
  6. Tap Found it at the real ball to log ground truth for later calibration.
  7. Add ?demo=1 to the URL to preview without a board (demo also fakes a short GPS trail).
